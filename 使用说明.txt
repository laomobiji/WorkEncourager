上班鼓励器 · 使用说明
========================================

文件在哪
  安装版（推荐）：双击 WorkEncourager-Setup.exe 安装
    程序装到 %LOCALAPPDATA%\WorkEncourager\App，桌面快捷方式自动创建，
    可勾选开机自启；卸载走 Windows「设置 → 应用」，或运行安装目录里的 uninstall.ps1
    配置和统计存在 %APPDATA%\WorkEncourager，重装/升级不会丢
  绿色版（免安装）：把仓库 clone 或下载解压到任意目录，双击其中的 start_widget.vbs
    work_widget.ps1    主程序（WPF 原生悬浮窗，不依赖 Python / 浏览器 / 第三方库）
    start_widget.vbs   启动器（静默启动，没有黑框，不占任务栏）

怎么开、怎么关
  开：双击桌面「上班鼓励器」，或双击 start_widget.vbs
  关：右上角 ✕，或右键菜单「退出」
  挪位置：按住窗口任意位置拖动，松手后位置会被记住
  右键菜单：取消置顶 / 回到右上角 / 主题 / 设置 / 刷新假日数据 / 嵌入桌面（当壁纸） / 退出

嵌入桌面（右键菜单勾选）
  勾上后悬浮窗压到所有窗口的最底层——平时完全看不到它，一显示桌面
  （Win+D 或看壁纸时）它就在那儿，像个桌面部件：
    · 不会盖住任何程序窗口，也不会被普通窗口的置顶顶掉
    · 点击它不会抢走当前窗口的焦点
    · Win+D 最小化后 1 秒内自动恢复
  再点一次菜单取消勾选，恢复普通置顶模式。选择会记住，重启后保持。
  注：弹出气泡（节点到账）不受影响，仍然浮在最上层。

参数设置（右键菜单「设置」，不用改脚本文件）
  可以直接在窗口里改：日薪、上下班时间、周末算不算钱、额外假日、
  四个节点奖励（金额 / 小卡标签 / 弹出标题）。
  填完点「保存」立即生效，配置存在 state.json 的 cfg 字段里。
  work_widget.ps1 开头的「可调参数」区现在只是首次运行的默认值，
  被 GUI 设置覆盖后就以 state.json 为准。
  注意：保存后当天已弹过的节点会重新生效（新金额的节点会补弹一次）。

法定假日自动识别（不用手动维护）
  每年自动联网获取国务院节假日安排（holiday-cn 数据，权威镜像），
  放假日和调休补班日都认识：
    · 法定假当天（哪怕在周末）→ 显示「不打工」
    · 调休补班的周六/周日     → 正常算打工
    · 本月「已打工天数」同样按这套算
  数据缓存在 %APPDATA%\WorkEncourager\holidays_年份.json，
  30 天内不重复联网，断网时用缓存，不影响使用。
  次年安排公布后（一般是每年 11 月底），点右键「刷新假日数据」即可；
  平时也会在新年后自动切到新一年的数据。
  设置里的「额外假日」是补充：公司自己放假、请假想休的日子填这里。

主题（右键菜单里切）
  内置 6 套：奶油粉（默认）/ 经典暗夜 / 抹茶拿铁 / 云朵蓝 / 蜜柚橙 / 葡萄汽水
  切换后立即生效并记住（存 state.json 的 theme 字段），下次启动还是它。
  想加自己的主题：work_widget.ps1 开头「主题」区照抄一份改色值即可，
  Key 不重复就会自动出现在右键菜单里。气泡颜色也跟着主题走。

界面上有什么
  大字          今日已入账金额，日薪 500 元 = 8.75 小时（8:00-16:45），保留 5 位小数，
                每 40 毫秒重算一次，所以小数末位一直在跳。
  进度条        今日进度，右侧「剩余 hh:mm:ss」倒计时到 16:45。
  四个小卡片    50 / 100 / 300 / 500 节点，达成后变绿并打勾，同时弹出提示气泡：
                  50  → 【已获得一个金铲铲皮肤】
                  100 → 【已获得一顿寿司郎】
                  300 → 【已获得一次滑雪票】
                  500 → 【打工圆满速速下班】
                每个节点一天只弹一次，重启不会重复弹；如果下午才开电脑，
                会补弹一条「你现在已经攒到的那一档」。
  本月          本月已打工 x 天（1 号到昨天，只数周一至周五，不含今天）
                累计 y = x × 500 + 今日实时金额（所以 y 也在涨）
                下面一行「相当于 · …」是按累计金额查表写死的文案，不联网。

想改参数（都在 work_widget.ps1 开头的「可调参数」区）
  $script:Wage           日薪，默认 500
  $script:StartH / StartM / EndH / EndM   上班 8:00，下班 16:45
                         注意小时和分钟要分开写：EndH=16 配 EndM=45。
                         别写成 EndH=16.45 —— 那会算成 16 小时 27 分。
                         界面上「xx:xx 收工」「xx:xx 才开工」和气泡文案都跟着这里走，
                         改完不用再改其他地方。
  $script:CountWeekend   周末算不算钱，默认 $false（周末显示不打工、今日 0）
  $script:Holidays       额外假日（公司放假/请假），写成 @('2026-12-25') 这样，
                         法定假日不用填这里，已自动识别
  $script:Milestones     节点金额、气泡标题、小卡片短标签、副文案
  $script:Tiers          本月累计金额 → 「相当于」文案的对照表
                         默认 0/50/100/150/200/300/400/500/700/1000/1200/1500/
                         2000/2500/3000/4000/5000/6000/8000/10000/12000/15000，
                         取「不超过当前金额的最大一档」

开机自启（可选，没帮你开）
  Win+R 输入 shell:startup 回车，把 start_widget.vbs 的快捷方式拖进那个文件夹。

数据存哪
  %APPDATA%\WorkEncourager\state.json   当天已弹过的节点 + 窗口位置 + 主题 + 设置
  %APPDATA%\WorkEncourager\holidays_2026.json   法定假日缓存（自动生成，可删，删了会重新联网拉）
  %APPDATA%\WorkEncourager\tick_error.log   只有出异常才会写，正常是空文件

调试参数（平时用不到）
  powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File work_widget.ps1 -Clock "18:30"
      用假时间预览界面。带了这个参数就完全不写 state.json，
      节点不会「弹过就记住」，窗口位置也不会被覆盖，放心开着调界面。
  ... -TestToast    启动时立刻把 4 条气泡按顺序演示一遍
